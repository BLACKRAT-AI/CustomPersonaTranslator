# 0.4.14: stop implicit app launching

The 18:30 requests exposed the difference between text submission and desktop access:
- The first request was blocked by an existing draft in the official app.
- The second was submitted as text, without a screenshot or CPT desktop tools.
- Every submission previously launched the official app unconditionally.

Voice submission now only uses an already visible official composer. Opening the app remains an explicit Settings action. Connection labels and hints identify the visible-chat adapter as text-only and point to the background Codex connection for screen/mouse control.

The installed C3PO profile uses background Codex with desktop access, fast mode and low reasoning effort. The previous settings are backed up. Other profiles, persona files, voice clips and trigger phrases are preserved.

Validation: 336 unit tests and UI smoke checks passed. An actual desktop test read a random code, entered it and clicked Verify in 20.6 seconds. The AppServices integration completed the action and persona answer in 21 seconds; the initial full run including cloned speech took 59.6 seconds. These timings do not justify a claim of instant voice response. The integration harness also checks audio after the final answer, separately from acknowledgement audio.
