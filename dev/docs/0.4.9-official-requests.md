# 0.4.9: spoken requests to the official app

The official-app connection previously received completed replies but discarded voice requests with a conversation-only warning. The compact panel hid that warning.

Spoken requests now activate the installed ChatGPT/Codex app, preserve any existing draft, populate its accessible composer, invoke Send once, and check for the submitted message. The visible chat remains the destination; this is Windows UI automation, not a private official API. The app must be signed in and its chat ready. Workspace setup and task execution remain controlled by the official app.

Status and errors are displayed in the compact bar's hint as well as its tooltip/toast. Worktree setup is recognized as a waiting state. UTF-8 without a BOM is now explicitly used for CLI stdin, fixing persona prompts containing Unicode punctuation.

Validation: 335 unit tests; window/settings/compact-panel smoke checks; real official-app send/reply round trip; real AppServices request, GPT answer, C-3PO rewrite and cloned audio (53.5 seconds including cold voice loading). This does not establish fast cold narration or benchmark computer tasks. Additional live checks exposed stale accessibility elements during chat re-rendering; submission confirmation now retries reads without resending.
