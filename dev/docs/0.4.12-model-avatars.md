# 0.4.12 ? Persona 3D avatars

Persona editor ? 3D avatar ? Choose 3D model accepts GLB files. Saving copies the model into the persona library, independently of the voice sample. Ordinary visual edits keep the learned prompt and clone. Persona packages include the GLB and framing settings.

The preview and floating panel use the same renderer. GLTFLoader, Three.js r160 and Meshopt decoder come from the local SYNTAX vendor files; MIT notices are included. SYNTAX's head-point rendering and amplitude-driven jaw movement are retained. New surface sampling detects named head meshes/parents and head-bone skin weights. If no head is labelled, tall models use the upper area. Framing, upper-area fraction, front direction and zoom are adjustable. This is geometry-based detection, not universal anatomical recognition. Models with unusual names/proportions may need manual framing. GLB is required; FBX/OBJ should first be exported as GLB. Draco-compressed models require an uncompressed export.

The application serves only explicitly selected model files through an intercepted resource URL; it does not expose the model's source folder. No network model service is used. Parsed model samples are cached across preview adjustments.

Checks: 336 .NET tests including model package round trip; UI construction and saved framing/voice-preservation checks; JavaScript geometry tests for named-head detection, fallback crop, whole model, zoom and invalid geometry; actual WebView rendering using SYNTAX's agent_head.glb with a captured preview.
