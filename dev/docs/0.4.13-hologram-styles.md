# 0.4.13 ? Hologram styles

Persona settings ? Hologram ? Style offers Particles (the unchanged default), Scan lines, Steam and Lasers. Preview hologram works with the default head as well as a selected GLB model. The style is saved per persona and included in exported persona packages; cosmetic saves preserve the existing voice sample and prompt.

All styles use the same head points, gaze, amplitude-driven jaw and mouth-shape parameters. Scan lines draw depth-curved horizontal contours with a travelling scan band. Steam combines a stable vapor face with slow drifting crown wisps. Lasers connect nearby surface points into filaments with travelling highlights and narrow projector beams. Alternate styles cache their mesh adjacency or vapor sprites; reduced-motion mode stops their ambient travel.

Validation: actual WebView captures inspected for all four styles; GLB loading and head detection; geometry regression checks; persona style/framing save checks; package round trip; .NET suite. The picker currently accepts GLB models. It does not perform universal anatomical recognition: automatic detection uses head mesh/bone names and a tall-body fallback, with manual framing controls provided for other models.
