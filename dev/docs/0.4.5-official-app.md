# 0.4.5 official desktop app connection

Configured agent: Official App, J.A.R.V.I.S. persona, displayed-chat observation. Existing CLI agents remain available. The floating composer opens the official app; it does not pretend to submit requests remotely. Stop voice cancels local narration only.

The verified Windows connection observes the installed OpenAI.Codex desktop app through UI Automation. It detects visible busy controls and completed English-language assistant replies, waits 1.5 seconds for stable text, and excludes accessibility status announcements. It follows whichever chat is displayed. The window must remain open and visible; hidden tool progress is not exposed. UI changes, localization, complex response widgets, or virtualization can affect extraction. This is not an official event API or proof that an agent action succeeded.

Original answers appear immediately after observation. Optional persona narration uses a fresh, independent rewrite conversation for each reply, then the existing voice pipeline. The configured rewrite provider is Codex CLI, Astra, low effort, Fast mode, with extensions off. Task execution itself stays in the official app. Narration adds model and speech latency; disable the narration checkbox for immediate text-only reporting. Repeat replays the saved persona response without executing the task again.

The Official App tab also provides Codex lifecycle hook installation/removal, diagnostics, observed sessions and explicit session linking. Hooks are asynchronous and use a current-user-only named pipe; only session/turn/event identifiers, prompt/final text, tool name and working directory are projected. Tool inputs, results and transcript files are not collected. Existing hooks are preserved and backed up. Native trust review is required. The six hooks were reviewed through the normal Codex hook UI during setup; the desktop general-chat test emitted no hook event. Hooks are therefore disabled in the user's configuration by default, with screen observation selected instead. They remain an optional integration for supporting clients.
